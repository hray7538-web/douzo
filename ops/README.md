```
   ③ 확인   조건을 손님에게 되묻어 확정한다
   ④ 예약   온라인 되는 곳은 직접 / 전화만 되는 곳은 작업지시서 → 사람
   ⑤ 통보   손님 말로 결과를 보낸다
   ⑥ 기록   손님·가게 양쪽을 기록한다        ← 이게 시스템의 심장이다
        │
        ▼
   ledger/  requests · guests · shops
```

## 🔴 ⑥이 왜 심장인가

「같은 문제를 두 번 보내지 않는다」는 약속은 **기록이 있어야만 참이다.**
기록이 없으면 그건 거짓말이고, 가게에 할 말이 사라진다.

가게에게 그 손님은 **일회성 외국인**이다. 우리에게는 **기록되는 사람**이다.
**가게가 못 기억하는 것을 우리가 기억한다** — 그게 우리가 파는 것이다.

## v1 원칙

- **자동화하지 않는다.** 처리는 사람(미치)이 한다. 건수가 늘면 그때 짠다
- **DB를 미리 만들지 않는다.** 요청이 오면 구글맵에서 그때 찾는다
- **가맹 계약이 없다.** 예약 대행은 가게 동의가 불요다. 나고야 전체가 재고다
- **결제 시스템이 없다.** 자율 과금이라 청구 자체가 없다
- **범위는 핫페퍼에 있는 업종만**
