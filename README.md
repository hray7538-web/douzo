# Douzo — Nagoya bookings, in your language

「書くだけ。予約します。」

나고야에 온 외국인이 **자기 말로 쓰면 예약이 잡히는** 서비스.
전화·일본어로만 예약을 받는 가게까지 포함한다.

## 구조
- `build.py` — 정적 사이트 생성기. 의존성 없음. `python3 build.py`
- `docs/` — 생성 결과. GitHub Pages가 여기를 서비스한다
- 언어 6 (en / ja / ko / zh-hant / zh-hans / th) × 업종 6 = **43 페이지**

## 바꾸는 곳
- `build.py` 상단 `CONTACT` — 접수받을 메일 주소 (지금은 임시)
- `LANGS` — 언어별 문안
- `CATS` — 업종별 SEO 페이지

## v1 원칙
- **DB를 만들지 않는다.** 요청이 오면 구글맵에서 그때 찾는다
- **가맹 계약이 필요 없다.** 예약 대행은 가게 동의가 불요
- **자동화하지 않는다.** 처음엔 사람이 처리한다. 건수가 늘면 그때
- 채널은 **AI가 자유로운 곳**만 — 자체 웹 SEO 주력, 유튜브·핀터레스트 보조
- 범위는 **핫페퍼에 있는 업종**만

## 법적 경계
- 항공·철도·버스·호텔을 취급하지 않는다 → 旅行業法 해당 없음 (제2조 각 호의 「付随して」 구조)
- 여정 제안·관광 플래닝을 하지 않는다 → 旅行業法 9호 회피. **예약 대행**으로 자기규정
- 마사지·의료는 v2·v3에서 (あはき법 · 医療広告)
