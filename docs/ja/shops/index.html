外国人のご予約を、
安心して受けられるように。

ヨヨイ（Yoyoi）は、訪日のお客様に代わって日本語でご予約をお取りするサービスです。お店側のご登録・掲載料・システム導入は一切不要です。

お店にとって何が変わるか

  • 条件は事前にすべて合意済みです。人数・時間・予算・アレルギー・宗教上の制限まで確認してからお電話します。席についてから話が変わることがありません。
  • 無連絡キャンセルを減らします。お客様とは予約前にやり取りをしています。連絡先が取れる状態です。
  • 問題のあったお客様は、二度お取り次ぎしません。お店では「一度きりの外国人のお客様」でも、私たちには記録が残ります。お店が覚えられないことを、私たちが覚えます。
  • 言語の負担がありません。やり取りはすべて私たちが日本語で行います。

お願いしたいこと

  • お電話でご予約をお受けいただくこと。それだけです。
  • ご登録・契約・掲載料はありません。断っていただいても構いません。

料金について

  • 価値があったと思われた額を、お店の方からお支払いいただけます。お支払いがなくてもお取り次ぎは変わりません。
  • 多くお支払いいただいても、優先的にご紹介することはありません。お金で順番を売りません。売った時点で、このサービスを信頼していただく理由がなくなります。

私たちが守ること

  • お店を評価し、お客様も評価します。片方だけを守ることはしません。
  • 国籍・人種・信条でお客様を選別しません。判断するのは行いだけです。
  • お客様の個人情報をお店にお渡しすることはありません。
