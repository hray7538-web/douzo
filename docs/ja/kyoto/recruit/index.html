京都のお店に、日本語でご予約のお電話をしていただくお仕事です。ご自宅から、スマートフォンだけでできます。

お願いしたいこと

  • 画面にそのまま読む文が出ます。お店にお電話して、読んでいただくだけです。
  • お店のお返事を、画面の三つのボタン（取れた・だめ・あとで）から選んでいただきます。
  • 1日に数件です。夕方前が中心になります。

こんな方に

  • 日本語でお電話ができる方。それだけです。
  • パソコンは要りません。スマートフォンが使えれば大丈夫です。
  • 外国語は一切必要ありません。お客様とのやり取りはこちらでいたします。

条件

  • ご自宅から（在宅）。週3日ほど、1日1〜2時間。
  • お電話1件ごとのお支払いです。金額は決まり次第、このページに掲載します。
  • 年齢は問いません。長くお勤めいただける方を探しています。

なぜ人にお願いするのか

  • お店との最初のやり取りは、人の声でなければ通らないと考えています。
  • AIが調べて文を用意し、人が話す。その分担でやっています。
